This player draws the picture itself instead of using the car’s built-in video player — the part Tesla pauses when the car leaves Park. For the passenger while the car is moving. Works with HLS streams and MP4 files (H.264 + AAC). Encrypted services like Netflix can’t run through any player like this.

This browser can’t run the drive-mode player. It doesn’t have WebCodecs (the video-decoding API this page needs). There’s no fallback player here on purpose — a regular video player would just freeze when the car moves. Try this page in the Tesla browser; if you see this message there too, the car’s current software can’t do it.

Direct stream

Paste an HLS stream address (ends in .m3u8, MPEG-TS segments) or a direct MP4 file address, then tap Play stream.

YouTube

Search YouTube and tap a result to watch it right here — your home helper converts the video so it plays in this player, in Drive too. You can also paste a YouTube link into the search box. The helper address is saved on this screen only.

Live TV

Free live channels — tap one to start watching. These are free-to-air streams from the iptv-org collection; channels come and go, so if one stops working, try another.

Your Plex library

Enter your Plex server address and token once — they’re saved only in this browser (local storage), never in this page. Use the address that works away from home (a plex.direct address if Remote Access is on, or your home address on home Wi-Fi).

Nate’s Theater. Video: H.264 only, decoded on this page with WebCodecs and painted to a canvas. Audio: AAC through Web Audio. HLS must use MPEG-TS segments (not fMP4) and be unencrypted; MP4 must be a single non-fragmented file.
